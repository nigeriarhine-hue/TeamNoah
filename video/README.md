# Noah — cinematic product video

A vertical short for YouTube Shorts / Reels / TikTok, built in Remotion.

**1080 × 1920 · 30 fps · 31.40 s · H.264 High + AAC stereo**

> Describe it. Approve it. Done.

## What it is

A thirty-second story, not a feature list. A computer feels slow; the obvious
answer is that it's old. Noah checks, finds seven programs launching at every
boot and ~30 running in the background, shows what it would do, waits for
permission, does it, and measures the same things again.

Every Noah screen in the film is a real capture of one real session. Nothing is
mocked up and no UI label is re-typed — see [`ASSET_MANIFEST.md`](ASSET_MANIFEST.md)
for the source of every frame, and [`TIMING.md`](TIMING.md) for the timing sheet.

## Running it

```bash
npm install
npm run build       # regenerate the Noah crops and the score (both are gitignored)

npm run dev         # Remotion Studio, to scrub and tweak

npm run render      # the film      → out/noah-pc-slowdown-short.mp4
npm run thumbnail   # the three PNGs → out/
npm run qc          # black-frame + luma-envelope check on the render
npm run typecheck
```

Renders here use the container's headless Chromium. On a machine where Remotion
manages its own browser, drop the `--browser-executable` path in
`scripts/render.mjs` and `scripts/qc-frames.mjs`.

## How it is put together

```
src/NoahAd/
  NoahAd.tsx              the composition: nine scenes, cross-dissolved
  theme.ts                brand tokens, mirrored from ../brand-kit.html
  layout.ts               the vertical grid and the headline+hero stack helper
  config/
    timing.ts             scene placement and audio cue sheet — one source of truth
    copy.ts               the script, including the ready-to-activate VS Code / Git variant
    assets.ts             every file path the film touches
    asset-sizes.ts        GENERATED — true pixel sizes, so nothing is ever stretched
  components/             PremiumAppFrame, NoahPanel, CinematicText, AnimatedCursor,
                          UIFocus, GlowBackground, NoahLogo, CodeLine, CTA, …
  scenes/                 one file per beat
src/Thumbnail/            the thumbnail, with editable headline copy
scripts/
  process-assets.mjs      screenshots → aligned, upscaled, sharpened crops
  synth.mjs               a small offline synthesiser
  build-audio.mjs         the score and sound design, generated against the cue sheet
  render.mjs              final renders
  qc-frames.mjs           representative stills for review
  check-frames.mjs        automated black-frame / dropout check
```

`public/noah/` and `public/audio/` are derived and not committed — `npm run build`
regenerates both deterministically from the screenshots at the repository root
and the cue sheet in `config/timing.ts`.

### Swapping assets

Paths live in `src/NoahAd/config/assets.ts`. Replace a file in `public/` and the
film picks it up. To re-cut from new screenshots, add a crop to
`scripts/process-assets.mjs` and run `npm run assets` — it regenerates
`config/asset-sizes.ts`, so panels keep their true aspect ratio automatically.

### Re-cutting the action button

The plan's action button carries a product label that changes as Noah ships.
`scripts/process-assets.mjs` finds it by pixel rather than by coordinates, so:

```bash
# 1. drop the newer plan screenshot at the repository root
# 2. point BUTTON_SOURCE at it in scripts/process-assets.mjs
npm run assets && npm run render
```

The detector locates the blue-to-violet pill regardless of window size, scale or
DPI, and fails loudly rather than cropping the wrong thing. Panel height follows
the new aspect ratio automatically via `config/asset-sizes.ts`.

### Swapping the story

`config/copy.ts` also exports `vsCodeGitStory`, the macOS / VS Code / Git script.
It is not rendered because no Noah captures of that session exist yet. Drop those
screenshots into `public/noah/`, point `config/assets.ts` at them, and switch the
`copy` import — the scene code needs no changes.

### Audio

The score and every sound effect are generated by `scripts/build-audio.mjs`
against the cue times in `config/timing.ts`, so motion and sound stay in sync
even when timing changes. It is original material — royalty-free, no third-party
rights. To use a supplied track instead, replace `public/audio/noah-score.wav`.

### A horizontal cut

The composition is resolution-driven rather than hard-coded: scenes place
content through `layout.ts` against the canvas centre. A 1920×1080 cut means
adding a `Composition` with those dimensions and widening the stack helper's
assumptions — the vertical short was not compromised to allow for it.

## Brand rules

`brand-pack/README.md` governs the mark: no recolouring, no stretching, no
rotation, no effects on the logo itself, and clear space around it. The reveal
is limited to opacity and uniform scale; ambient light sits behind the mark,
never on it.
