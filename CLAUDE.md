# TeamNoah — working notes

## Video / post descriptions
- Every YouTube / TikTok / social description for Noah content must end with the standard Noah description in
  `seo/noah-standard-description.md` (after the video-specific copy and the onnoah.app link, before hashtags).
- Use the PC version when the video shows the Windows app or says "PC"; use the Mac version otherwise.
- Don't edit the standard text beyond the Mac/PC swap.

## Brand reminders
- Always write "Noah". Educational first, Noah late; no fake findings, no "guaranteed faster", never the word "IT".
- Noah UI in videos must come from the real screenshots (see `src/components/noahScreenData.ts`).
